# 💈 LuX Cortes - Sistema de Gestão e Automação para Barbearias<img width="576" height="1280" alt="WhatsApp Image 2026-09-10 at 00 02 24" src="https://github.com/user-attachments/assets/662a5fc9-b10b-4547-a9f8-d86f823e6fbd" />


Plataforma full-stack desenvolvida para automatizar o fluxo de agendamentos e pagamentos de barbearias, eliminando processos manuais, otimizando o fluxo de caixa e integrando confirmações via WhatsApp em tempo real.

---

## 🚀 Sobre o Projeto

O **Lux Cortes** nasceu da necessidade de criar uma solução moderna, enxuta e totalmente automatizada para o gerenciamento de barbearias. O sistema resolve gargalos operacionais comuns do dia a dia por meio de arquitetura de microsserviços, banco de dados relacional e automações de ponta a ponta, servindo como um ecossistema funcional em produção para testes e validações de mercado.

---

## 🛠️ Tecnologias e Stack Utilizadas

### Front-end
* **React** / **JavaScript (ES6+)**
* **HTML5** / **CSS3** (Interfaces responsivas e intuitivas)
* Hospedagem e Deploy contínuo na **Vercel**

### Back-end & Infraestrutura
* **Node.js**
* **PostgreSQL** (Banco de dados relacional robusto)
* Hospedagem de servidores e APIs na **Railway**

### Automações & Integrações (Webhooks e APIs)
* **n8n** (Orquestração de fluxos e automações de suporte)
* **Evolution API** (Integração direta com o WhatsApp para disparos e filtros)
* **API de Pagamentos / Webhooks** (Geração de QR Code e confirmação instantânea)

---

## ⚙️ Principais Funcionalidades

1. **Geração Dinâmica de QR Code**: O cliente realiza a transação e o sistema processa os dados de pagamento de forma instantânea.
2. **Confirmação Automatizada via WhatsApp**: Integração com a Evolution API e n8n que dispara mensagens de confirmação e validação de pagamento em tempo real, sem intervenção humana.
3. **Painel de Controle Administrativo (Dashboard)**: Gerenciamento completo de clientes, status de pagamentos e histórico de agendamentos conectados a um banco de dados SQL.
4. **Filtro Inteligente de Suporte**: Automações que reduzem o atrito no atendimento ao cliente, entregando fluxos limpos e diretos.

---

## 🌐 Acesso ao Projeto

O sistema está estruturado para testes em ambiente real. Você pode acessar a aplicação em funcionamento e testar a geração de QR codes, webhooks e respostas via API em tempo real através dos links de produção hospedados nas plataformas.
